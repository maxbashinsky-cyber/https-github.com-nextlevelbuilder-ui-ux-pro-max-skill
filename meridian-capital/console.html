Runbook — paper to live

01Paper-trade locally (no keys needed)

Deterministic simulation: deposit, trade, inspect. This is what generated the data on this page.

cd meridian-capital/quant
python3 trader.py --mode paper \
  --deposit 250000 --days 130

02Connect a real paper account

Create free API keys at alpaca.markets (Paper). The daemon trades the same book against live market data with zero real money.

export APCA_API_KEY_ID=...
export APCA_API_SECRET_KEY=...
python3 trader.py --mode alpaca-paper

03Automate the daily rebalance

One cron entry. The daemon is idempotent — each run computes signals, diffs the book, sends only what changed.

# 3:45pm ET, weekdays
45 15 * * 1-5 cd .../quant && \
  python3 trader.py --mode alpaca-paper \
  >> ../live/trader.log 2>&1

04Go live — deliberately

Only after weeks of paper validation. Fund the account at your broker; the extra env var is a deliberate speed bump. If the kill switch trips, the daemon stays flat until you delete live/state.json.

MERIDIAN_CONFIRM_LIVE=yes \
  python3 trader.py --mode alpaca-live
Important. This console reports what the automated daemon did; it does not predict what markets will do. Backtested or simulated edge does not guarantee live alpha — live results differ due to slippage, borrow costs, capacity and regime change.
